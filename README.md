# yakın · kar küresi

Low-poly 3D snow globe of the **yakın** café, with Can the barista and Havlu the café dog.

**Live:** https://firatmelih.github.io/yakincafe/

- Season: spring, summer, autumn, winter. The weather follows the season: petals, sunshine, rain and falling leaves, snow.
- Day / night. The lights follow the time: by day only the indoor lamps are on.
- Spin: only the platform inside the globe turns. Zoom in to see inside; double-click to shake the globe.

The model was built in Blender (scripts are not included) and runs on [three.js](https://threejs.org) (MIT). Font: [Nunito](https://fonts.google.com/specimen/Nunito) (SIL OFL).

Music: **"Kahve Molası"**, an original lo-fi café loop composed for this site and synthesised live in the browser with the Web Audio API (electric piano, bass, soft drums, vinyl crackle). There is no audio file and no third-party music. Browsers allow no sound before an interaction, so it starts on the first touch, click or key press; the player is at the top right.
